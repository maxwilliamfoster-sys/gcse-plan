# Max's GCSE Plan

A GCSE revision planner for summer 2027: a daily plan built from topic confidence ratings, spaced repetition, exam dates and interleaving, plus flashcards, topic knowledge cards and the full exam timetable.

**Live:** https://maxwilliamfoster-sys.github.io/gcse-plan/

- `src/` — subject data (`d-*.js`), engine + UI (`app.js`), styles, shell
- `py build.py` → `docs/index.html` (GitHub Pages) and `dist/` (single-file builds)

Progress is saved in the browser's local storage on each device.
